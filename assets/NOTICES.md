# 大肥鱼素材来源

随包素材对应 [louke6572/dsh-Dfy 的固定版本](https://github.com/louke6572/dsh-Dfy/tree/54c22d7811f183a3dbf78f29bfe91e045e964755)。桌面动画使用原始透明 WebM。ESP32 版本使用同源的 RGB565/RLE 帧，动作名与桌宠一致。转换文件与原始文件的指纹见 [ESP32 清单](esp32/manifest.json)。

- 106 段桌宠动画源自 PC2005-cloud/dsh-pet，保留 [MIT 许可](licenses/dsh-pet-MIT.txt)。
- 角色图与表情素材按原提供者授权随包使用，许可范围见[来源说明](licenses/upstream-PROVENANCE.md)。此类素材独立于软件代码许可。
- 桌宠运行时通过锁定的 npm 依赖安装。[dsh-Dfy 代码许可](licenses/dsh-Dfy-LICENSE.txt) 随引用素材保留。
